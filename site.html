Atendimento universal

Um chat. Qualquer site.

Instale uma única linha de JavaScript em qualquer página. Cada carregamento gera um canal independente no Firestore. Todas as conversas chegam automaticamente à Central de Atendimento.

Instalar chat Ver código

Universal

Funciona em HTML, WordPress, Shopify e qualquer site.

Tempo real

Mensagens sincronizadas entre visitante e atendente.

Multicanal

Todos os sites centralizados em um único painel.

Como funciona

1. Visitante acessa o site

O JavaScript identifica título, URL e domínio.

2. Canal criado

Um novo documento é criado em Firestore / channels.

3. Visitante envia mensagem

A mensagem é salva na subcoleção messages e incrementa unread.

4. Painel recebe notificação

A conversa aparece na Central com indicador de mensagens não lidas.

Instalação

Adicione esta linha antes do fechamento do body de qualquer página.

<script src="https://SEU-DOMINIO.com/chat-global.js"></script>

Não é necessário instalar Firebase no site cliente. O SDK é carregado pelo próprio script.

Configuração do atendente

Edite estas constantes no início do script.

const AGENT = {
  name: "Equipe de Atendimento",
  photo: "https://SEU-DOMINIO.com/atendente.jpg",
  status: "Online"
};

   Segurança antes de publicar
   

    As credenciais Firebase no JavaScript identificam o projeto, mas não são autenticação. Para produção, proteja o painel com autenticação, use regras que impeçam visitantes de ler outros canais e valide a autorização de cada mensagem. Uma solução adequada é autenticação anônima para visitantes combinada com regras por UID e controle de acesso do atendente.
